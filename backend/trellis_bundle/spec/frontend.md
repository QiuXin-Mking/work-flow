# Frontend context

- Trace the visible state to its API response, client state, and rendering path before editing.
- Preserve TypeScript types and handle loading, empty, error, and stale response states.
- Check component behavior with realistic user interaction and verify the affected view at its supported viewport sizes.
- Keep existing design conventions and accessibility labels unless the Bug calls for a change.
- When an API field changes, check the backend producer and all frontend consumers together.
